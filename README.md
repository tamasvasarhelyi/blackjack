# Blackjack

A simple terminal-based Blackjack game written in Python.

This project is my own implementation inspired by *The Big Book of Small Python Projects* by Al Sweigart. I built it as a Python practice project and plan to improve it step by step.

## Current Features

- Standard 52-card deck
- Random deck shuffling
- Player and dealer hands
- Hit and stand actions
- Correct handling of aces as 1 or 11
- Dealer draws until reaching 17
- Win, loss, and draw detection
- Hidden dealer card during the player's turn

## Planned Improvements

- Betting system
- Double down
- Multiple rounds
- ASCII card display
- Red and black card colors
- Improved terminal interface

## Running the Game

Requires Python 3.13 or later.

Run the game from the terminal:

```bash
python blackjack.py
```
